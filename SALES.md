# Sales Summary Dashboard

## Project Overview

Created an interactive **Sales Summary Dashboard using Microsoft Power BI** to analyze sales performance, revenue, profit, products, regions, and sales trends.

## Tool Used

* Microsoft Power BI

## Key Analysis

* Total Sales by year and category
* Total Sales by category
* Region contribution in profit
* Sales, Profit and Profit ratio by category
* Returned Orders by Market
* Top 5 Regional Managers by Sales

## Skills Demonstrated

* Data Cleaning
* Data Transformation
* Data Modeling
* DAX
* Data Visualization
* Power BI Dashboard Development
